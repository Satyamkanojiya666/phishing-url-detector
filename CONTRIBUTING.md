# Contributing

Thanks for helping improve PHISH//HUNTER, created by Satyam Kanojiya!

1. Fork the repo and create a branch: `git checkout -b feature/my-change`
2. Install dev dependencies: `pip install -r requirements-dev.txt`
3. Make your change and add/adjust tests in `tests/`
4. Run `pytest` — all tests must pass
5. Open a pull request describing what and why

Good first contributions: more training data (`data/custom_dataset.csv`), new URL heuristics in `detector.py`,
more languages for keyword lists, UI improvements.
